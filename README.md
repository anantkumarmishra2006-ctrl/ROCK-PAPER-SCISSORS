# 🪨 Rock Paper Scissors

A simple Rock Paper Scissors game built using HTML, CSS, and JavaScript. It allows users to play against the computer with an interactive and user-friendly interface.

## 🛠️ Technologies
- HTML
- CSS
- JavaScript

## ✨ Features
- Player vs Computer
- Winner detection
- Interactive buttons
- Responsive design

## 🚀 How to Play
Open `index.html` in your browser and choose Rock, Paper or Scissors.
