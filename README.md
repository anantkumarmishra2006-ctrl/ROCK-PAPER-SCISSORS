# 🪨 Rock Paper Scissors

A simple Rock Paper Scissors game made using HTML, CSS and JavaScript.

## 🛠️ Technologies
- HTML
- CSS
- JavaScript

## ✨ Features
- Player vs Computer
- Winner detection
- Interactive buttons
- Responsive design

## 🚀 How to Play
Open `index.html` in your browser and choose Rock, Paper or Scissors.
